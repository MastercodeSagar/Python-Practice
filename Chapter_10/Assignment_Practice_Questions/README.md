# Chapter 10 Assignments: Modules

1. Use `math` to calculate a square root.
2. Use `random` to create a number guessing game.
3. Use `datetime` to calculate a person's age in days.
4. Use `pathlib` to list files in a folder.

6. Import your module into a second file.
7. Use `json` to save and load a profile.
8. Use `statistics` to calculate mean and median.
9. Use `string` to build a character set.
10. Build a small program using at least three standard-library modules.
