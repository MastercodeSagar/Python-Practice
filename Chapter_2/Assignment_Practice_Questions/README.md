# Chapter 2 Assignments: Variables and Input

1. Ask for a user's name and greet them.
2. Ask for two numbers and print their sum.
3. Ask for a birth year and calculate an approximate age.
4. Convert a temperature entered as text to a float.
5. Ask for the price and quantity of an item and print the bill.
6. Swap the values of two variables.
7. Ask for a student's name and three marks, then print the average.
8. Convert kilometres entered by the user to miles.
9. Ask for a city and country and print a formatted address.
10. Build a simple receipt using variables and f-strings.
