# Logical Programs for Interview Practice

These are separate runnable programs for common logic questions. Read the
definition, predict the output, run the file, and then rewrite it yourself.

1. `01_Palindrome.py` - checks whether text reads the same backward.
2. `02_Prime_Number.py` - checks whether a number has only two factors.
3. `03_Factorial.py` - multiplies all positive numbers up to a number.
4. `04_Fibonacci.py` - generates the Fibonacci number sequence.
5. `05_Armstrong_Number.py` - checks a digit-power sum property.
6. `06_Character_Frequency.py` - counts how often characters appear.
7. `07_Anagram.py` - checks whether two words use the same letters.
8. `08_Linear_Search.py` - searches a list one item at a time.
9. `09_Bubble_Sort.py` - sorts values by repeated comparisons.
10. `10_Second_Largest.py` - finds the second-largest unique value.
