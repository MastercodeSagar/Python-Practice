# Chapter 6 Assignments: Strings

1. Count the characters in a sentence.
2. Count the vowels and consonants in a word.
3. Reverse a string without using a built-in reverse function.
4. Check whether a word is a palindrome.
5. Count how many times a character appears.
6. Replace spaces with hyphens.
7. Extract the first and last word from a sentence.
8. Convert a sentence to title case.
9. Check whether a sentence contains a search word.
10. Remove duplicate characters from a string.
